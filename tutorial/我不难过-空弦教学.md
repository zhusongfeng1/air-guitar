# 用"空气吉他"弹《我不难过》—— 6 根空弦版教学

> **先说结论**：《我不难过》是 **C 调**，所以把**整体变调设成 +5**，
> 6 根弦就变成 `A2 D3 G3 C4 E4 A4`，音级 {A C D E G} 全在 C 大调里。
> C 调七个和弦里**五个能弹根音**，只有 F 要用它的五度 C 代替 —— 完整的表在**第 7 节**，
> 拿着任何一份 C 调谱子现在就能弹。试听在 `tutorial/demo-Cmaj-C-G-Am-F.wav`。

> 原曲**具体的和弦顺序**（主歌/副歌各是什么进行）我没能联网核实（`web_search` 插件报 401，
> Bing 走代理只回缓存垃圾，百度百科 403，维基/lite-duckduckgo/guitarians 连不上，mojeek 403，91 谱要登录），
> 我不会凭记忆把和弦写给你。你把顺序发我（比如"主歌 C G Am F，副歌 F G C C"），
> 我就把它排成一小节一格的整曲谱并渲染试听。

> 但**不影响你现在就弹**：第 7 节那张表把 C 调七个和弦全列了，查表即可。

## 1. 先认清这把琴的真实能力（这决定了一切）

我读了 `web/js/audio.js` 和 `app.js`，它现在是这样的：

| 能力 | 现状 | 含义 |
|---|---|---|
| 音高 | **只有 6 个：E2 A2 D3 G3 B3 E4** | 没有按品（`fret` 恒为 0），只有空弦 |
| 同时发声 | **一次一个音** | 拨弦 = 一只手张开，选中哪根弦就响哪根，不是扫和弦 |
| 音色 | 真实吉他采样（University of Iowa MIS） | 6 个音各 3 个力度层（pp/mf/ff），共 18 个 wav |
| 变调 | **整把琴可平移 −5…+7 个半音**（本轮新加） | 平移后 6 根弦仍然是一个 m11 和声，但换了调 |

### 这意味着什么

6 个空弦音 = **E A D G B E**。把它们当一个和声看：

```
E2 ─ A2 ─ D3 ─ G3 ─ B3 ─ E4
根音  4度   b7度  b3度  5度   8度
```

也就是 **Em11**（或者把 A 当低音时是 **Am7add11**）。这是一个"**没有明暗、悬着**"的和声：

- 它里面**没有大三度也没有小三度**（相对 A 而言），所以配大多数小调、甚至不少大调的歌都不会难听；
- 它的色彩是"空、飘、叹气"，正好是《我不难过》这类慢歌要的味道。

**但代价是：它是单音的、只有 6 个音高。** 所以你不可能"照原谱弹"——**任何歌都必须改编**。
改编的方法就是把原曲的**低音线 / 和弦根音**量化到这 6 个音上（第 4 节有工具算）。

## 2. 手势对照表（这就是"指板"）

一只手选弦，另一只手张开拨弦。**选弦的手伸几根手指 = 哪根弦**：

| 选弦手的手势 | 弦号 | 变调 0 时的音 | 变调 +5 时（A 小调） |
|---|---|---|---|
| 伸 1 根（拇指不算时是食指） | **1 弦** | E4（最高） | A4 |
| 伸 2 根 | **2 弦** | B3 | E4 |
| 伸 3 根 | **3 弦** | G3 | C4 |
| 伸 4 根 | **4 弦** | D3 | G3 |
| 伸 5 根 | **5 弦** | A2 | D3 |
| 🤘（拇指+小指） | **6 弦** | E2（最低） | A2 |
| 握拳 | —— | 全部闷音 | 全部闷音 |

拨弦的手：**张开 = 拨弦**（上升沿触发，需要"张开幅度 ≥0.35"），**握起 = 闷音**。

> 两个实用提示：
> - **1 弦最容易误判**：拇指容易跟着翘。如果 1 弦老是不准，去换"弦映射 = 方案B（只数四根长指）"，
>   或者干脆用右侧的「手势校准」把你的 6 个手势各比划一遍。
> - **别一直张着手**：张开是"上升沿"触发，一直张着不会再响。要"握起 → 张开"才有一下。

## 3. 先把调对上（这是"对照谱子"的第一步）

拿到你的谱子，先看**这首歌唱的是哪个小调**（大调就看它的关系小调）。
然后在网页「音频」那一栏的**整体变调**里选对应的调：

| 歌的调 | 变调 | 6 根弦变成 |
|---|---|---|
| C 小调 / Eb 大调 | **−4** | C2 F2 A#2 D#3 G3 C4 |
| C#(Db) 小调 | −3 | C#2 F#2 B2 E3 G#3 C#4 |
| D 小调 / F 大调 | **−2** | D2 G2 C3 F3 A3 D4 |
| D#(Eb) 小调 | −1 | D#2 G#2 C#3 F#3 A#3 D#4 |
| **E 小调 / G 大调** | **0**（默认） | E2 A2 D3 G3 B3 E4 |
| F 小调 | +1 | F2 A#2 D#3 G#3 C4 F4 |
| F#(Gb) 小调 | +2 | F#2 B2 E3 A3 C#4 F#4 |
| G 小调 / Bb 大调 | +3 | G2 C3 F3 A#3 D4 G4 |
| G#(Ab) 小调 | +4 | G#2 C#3 F#3 B3 D#4 G#4 |
| **A 小调 / C 大调** | **+5** | A2 D3 G3 C4 E4 A4 |
| A#(Bb) 小调 | +6 | A#2 D#3 G#3 C#4 F4 A#4 |
| **B 小调** | **+7**（或 −5，低一个八度） | B2 E3 A3 D4 F#4 B4 |

选完之后，网页上那排弦按钮会**直接写上新音名**（比如 `1弦 A4`），面板上也会显示"6 根弦：A2 D3 G3 C4 E4 A4"。
**先空弹几下听一遍这 6 个音**，记住它们的高低顺序，再开始弹歌。

## 4. 把和弦走向变成"该弹哪根弦"

**规则**（这是改编的核心，只有三步）：

1. **能找到就弹根音** —— 这个和弦的根音正好是 6 根弦之一。
2. **找不到就弹五度** —— 五度最稳，听上去仍然是这个和弦（比如 F 和弦，弦里没有 F，就弹 C）。
3. **五度也没有就弹三度** —— 再不行就只能放弃这个音，或者整体换个变调。

仓库里有一个脚本专门算这件事，你自己就能跑：

```bash
cd air-guitar
node tutorial/fit_progression.mjs "Am F C G" --transpose=5
node tutorial/fit_progression.mjs "Am F C G" --transpose=5 --wav=试听.wav   # 顺便渲染成 wav 试听
```

它会输出每个和弦该弹哪根弦、是什么身份（根音/五度/邻音）、差多少音分，
**差超过 50 音分的会打 ⚠**（那种弹出来是走音的，必须换替代音）。

实测几个走向（这些是真跑出来的）：

```
A 小调（+5，弦 = A2 D3 G3 C4 E4 A4）
  Am → 6弦 A2（根音）        F  → 3弦 C4（五度，替代）    ← 弦里没有 F
  C  → 3弦 C4（根音）        G  → 4弦 G3（根音）          4/4 全都不走音

E 小调（0，弦 = E2 A2 D3 G3 B3 E4）
  Em → 6弦 E2（根音）        C  → 3弦 G3（五度，替代）    ← 弦里没有 C
  G  → 3弦 G3（根音）        D  → 4弦 D3（根音）          4/4 全都不走音

C 小调（如果误设成 −3，弦 = C#2 F#2 B2 E3 G#3 C#4）
  Cm → 6弦 C#2（邻音，差 100 音分）⚠    ← 这就是"变调设错了"的样子
```

**看到 ⚠ 就说明变调选错了**（调没对上），回去第 3 节重选。

## 5. 右手节奏型（慢歌用这个）

一次一个音，所以走的是**分解和弦**（琶音）那条路。以 4/4、每小节一个和弦为例，
每 0.5 拍一格，`·` 是空拍：

```
拍位：   1    &     2    &     3    &     4    &
弦：    低音   ·     ·    中音   高音   ·     中音   ·
        ↑                              ↑
       换和弦就弹新根音              挑一根高音弦点缀
```

具体点，用 A 小调（+5）的 `Am` 举例（低音 = 6弦 A2，中音 = 3弦 C4，高音 = 2弦 E4）：

```
1   &   2   &   3   &   4   &
6弦 ·   ·   3弦 2弦 ·   3弦 ·
A2          C4  E4      C4
```

`tutorial/render_demo.mjs` 里的 `DEMO` 就是这个型（4 小节 24 个音），已经渲染成两个 wav 给你听：

| 文件 | 说明 |
|---|---|
| `tutorial/demo-Aminor.wav` | 变调 +5，A 小调空弦版（13.6 秒）——**推荐先听这个** |
| `tutorial/demo-Eminor.wav` | 变调 0，原调空弦版，同一个型 |

**这两个文件是用真实采样离线渲染的**，和网页里响的是同一套规则（同一份 wav、同样的力度分层、
同样的播放速率和包络），所以听到的≈网页里会响的。

## 6. 练习顺序（别一上来就弹整首）

1. **认弦**：不开歌，就反复"伸 N 指 → 张开"，从 6 弦到 1 弦走一遍，再走回来。
   目标是**不用看手就知道自己伸出的是几根**。
2. **认调**：设好变调，从最低弦到最高弦弹一遍，把这 6 个音的高低顺序记住。
3. **两下**：只弹低音弦，一小节一下（`1` 和 `3` 拍各一下），打拍子。
   这是最简单的伴奏，已经能跟唱了。
4. **加花**：在第 3 拍加一个高音弦（第 5 节的型）。
5. **换和弦**：第 4 节算出来的和弦顺序，一小节换一个，手换来换去。
6. 到这一步，整首歌就是"换和弦 + 重复第 4 步的型"。

## 7. C 大调（《我不难过》的调）：一整张对照表，直接查

你说这首一般是 **C 调**，那就定下来：**整体变调设成 +5**，6 根空弦变成

```
6弦 A2   5弦 D3   4弦 G3   3弦 C4   2弦 E4   1弦 A4
```

为什么是 +5：这 6 个音的音级是 **{A C D E G}**，**全部落在 C 大调里**（C D E F G A B）。
缺的只是 **F 和 B** —— 所以整首歌里只有 F 和弦的根音弹不出来（Bdim 也很别扭），其它都能对上。

### C 大调七个级数，每个该弹哪根弦（这张表是算出来的，不是估的）

| 和弦 | 该弹 | 弦 | 身份 | 说明 |
|---|---|---|---|---|
| **C** | C4 | 3 弦 | 根音 | ✅ |
| **Dm** | D3 | 5 弦 | 根音 | ✅ 而且这个 D 比 C4 低，当低音正好 |
| **Em** | E4 | 2 弦 | 根音 | ✅ |
| **F** | C4 | 3 弦 | **五度替代** | ⚠ 弦里没有 F。弹 C（F 的五度）或 A（F 的三度）都不难听 |
| **G** | G3 | 4 弦 | 根音 | ✅ |
| **Am** | A2 | 6 弦 | 根音 | ✅ 最低那根，A 小调的主音 |
| **Bdim** | D3 | 5 弦 | 三度替代 | ⚠ 这首里基本不会出现，真遇到就弹 D |

**七个里五个能弹根音**，F 用五度替。这就是全部难点——没有别的了。

### 常见 C 调走向，照抄就行

| 走向 | 该弹的弦（一小节一个） |
|---|---|
| **C → G → Am → F** | 3弦 C4 → 4弦 G3 → 6弦 A2 → 3弦 C4 |
| **C → Am → F → G** | 3弦 C4 → 6弦 A2 → 3弦 C4 → 4弦 G3 |
| **Am → F → C → G** | 6弦 A2 → 3弦 C4 → 3弦 C4 → 4弦 G3 |
| **F → G → C → C** | 3弦 C4 → 4弦 G3 → 3弦 C4 → 3弦 C4 |
| **C → Em → Am → F** | 3弦 C4 → 2弦 E4 → 6弦 A2 → 3弦 C4 |

> 注意 F 和 C 都落在 **3 弦 C4** 上，所以 `… F → C …` 这种进行**低音不用动**——
> 听起来是"悬着不解决"，跟这首歌那种忍着不哭的感觉反而挺配。
> 想让它有走动感，就把 F 那一小节改弹 **6弦 A2**（F 的三度）。

试听：`tutorial/demo-Cmaj-C-G-Am-F.wav`（C→G→Am→F，72bpm，真实采样渲染，14.9 秒）

### 怎么用这张表弹整首歌

1. **把手上的谱子摊开**，只看每小节是哪个和弦，别管别的；
2. 一个和弦一小节：第 1 拍弹表里那根弦（低音），第 3 拍再弹一下，中间可以补一根高音弦；
3. 换和弦就换弦 —— 弹哪根弦，看屏幕上**六弦板**哪一行亮了就行。

《我不难过》的具体和弦顺序（主歌/副歌各是什么进行）我没能联网核实，
**但你只要照着上面这张表查，任何一份 C 调谱子现在都能弹了** —— 因为 C 调的七个和弦都在表里。
你把和弦顺序发我（比如"主歌 C G Am F，副歌 F G C C"），我再把它排成一小节一格的整曲谱。

## 8. 屏幕上会亮什么（六弦板）

拨弦的反馈直接画在画面上，不用去看右边面板：

- **六弦板**（画面下方）：6 行 = 6 根弦，从上到下是 6→1 弦。每行写着
  **手势符号 · 弦号 · 音名 · 你拨了多少次**。
  - 手势已经锁定某根弦、但还没拨 → 那一行**淡蓝高亮**（"预选"）；
  - 真的拨响 → 那一行**变绿 + 那条弦抖一下**，计数 +1；
- **画面中央的大字**：拨响的瞬间飘出一个 `🤘 6弦 · A2`，符号就是你要比的手势；
- **TAB 条**：最近 14 次拨弦的弦号+音名，**这一条就是你刚才弹出来的谱子**。
  旁边「复制 TAB」能把"弦序 + 各弦次数"复制成文本，方便贴到记事本里对着谱子改。

> 为什么要做这个：弹的时候人是盯着自己的手和画面的，
> 右侧面板里的文字**根本不会去看**。拨弦的反馈必须落在视线里，
> 而且要一次给全"哪根弦 + 什么音 + 什么手势"这三件事，否则学不会自己弹的是什么。

## 9. 想弹得更像原曲怎么办

现在的瓶颈是**只有 6 个音、而且不能按品**。要弹"真的像"，有两个方向：

- **A. 加"按品"**（推荐）：`web/js/audio.js` 里的 `pluck()` **本来就支持 `fret`**（用播放速率升半音，代码已经在了），
  只是界面没暴露。加上"拨弦的手在张开前伸几根手指 = 按第几品"，6 根弦 × 6 个品位 = 36 个音，
  就能弹真正的旋律了。这是小改动（trigger 那边已经有 `prevString` 那套"记住上一个状态"的机器可以复用）。
- **B. 加"扫弦"**：一次拨多根弦（`strum()` 也已经写好了），做成和弦伴奏。
