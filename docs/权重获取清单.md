> 本项目的引擎是**双引擎**：`handpose_x`（你给的开源项目，需要权重）和 `MediaPipe HandLandmarker`（兜底，已自动下载好）。
> 权重没到位也能玩，页面会自动退回 MediaPipe；权重一到位，改一个开关就切成 handpose_x。

## 二、打开网盘链接后下哪个

预训练模型那个分享里应该是一个压缩包（名字类似 `weights.zip` / `handpose_x_weights.zip`），**整个下下来**就行。里面按作者 README 的说法包含：

- 各种 backbone 的 `.pth`：`resnet_50-size-256-wingloss102-0.119.pth`、`ReXNetV1-size-256-wingloss102-0.122.pth` 等
- **一个已经转好的 `resnet50` 的 `.onnx`** ← 我们最想要这个

**优先级：**

1. **`.onnx` 那个文件（首选）** —— 纯浏览器里用 `onnxruntime-web` 直接跑，不需要 PyTorch，不需要装任何 Python 包。
2. 只有 `.pth` 也行 —— 需要我用 PyTorch 转一次 onnx（我会在工作目录里装，装不下就要你给一次权限）。
3. 两者都找不到 —— 告诉我压缩包里到底有哪些文件（截图或文件名列表），我按实际内容适配。

## 三、下好放哪里

把**压缩包原封不动**丢到这个目录就行，不用解压（我会自己解）：

```
air-guitar/incoming/
```

放好后跟我说一声"放好了"。我会自动扫描出权重文件、识别是 `.onnx` 还是 `.pth`，并生成/校验。

如果你想自己指定位置，也可以直接解压后把 onnx 放到：

```
air-guitar/web/vendor/models/handpose_x_resnet50.onnx
```

放好后刷新网页，右上角引擎会显示 `handpose_x (onnx)`。

## 四、我会怎么校验它真的能用

1. 检查文件大小和 onnx 的输入输出张量形状（应该是 `1×3×256×256` 进，`1×42` 出）；
2. 拿作者仓库自带的样例图（`third_party/handpose_x/image/*.jpg`）跑一次推理，把 21 个关键点画出来存成图；
3. 把图画给你看，确认关键点是真的落在手上，而不是乱飞。

## 五、关于"手部检测"

作者 README 第 39 行写明：

> 注意：该项目不包括手部检测部分。

也就是说 handpose_x **只负责"给定一张裁好的手图，回归 21 个关键点"**，它不知道手在画面哪里。所以完整链路是：

```
摄像头帧 → MediaPipe 手掌检测（出 bbox）→ 按作者 README 的 1.1 倍方形裁剪 → handpose_x → 21 关键点 → 手势 → 发声
```

裁剪规则严格照抄作者 `inference.py` / README 第 141-158 行的做法（`w_ = max(|x2-x1|,|y2-y1|) * 1.1` 的方形框）。
